Expand description

A block-granular transport: read or write one whole filesystem block, or report the disk size. The EL0 binary implements this over blk IPC; a host test implements it over a Vec.

This exists so the chunking that bridges RedoxFS’s byte-addressed, arbitrary-length Disk calls to whole-block transfers is written once and host-tested, instead of living only in the EL0 binary where no host test can reach it. That gap is what let the repeat-write bug hide.
