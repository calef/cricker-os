pub fn damaged_image(pristine: &[u8], log: &[Write], damage: Damage) -> Vec<u8> ⓘ
Expand description

Rebuild the image the platter would hold after damage, from the pristine image and the log.

Writes are numbered from 1 in issue order, matching how a person counts them when reading a trace. The pristine image is never modified.
